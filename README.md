# CV interactif — Victor Travers

Version **V9.2** du CV interactif de Victor Travers, spécialisé en marketing et droit des assurances. Le site permet à un recruteur de choisir plusieurs compétences techniques, puis de consulter trois réalisations adaptées à ses besoins et d'ouvrir des fiches détaillées.

## Hébergement gratuit — GitHub Pages

1. Dans **Settings → Pages**, choisissez **Deploy from a branch**.
2. Sélectionnez **main** et **/(root)**, puis cliquez **Save**.
3. L'adresse du site sera : **https://victortravers79-hash.github.io/cv-interactif/**.

Les fichiers du site sont sur la branche `main`, y compris `index.html`, les images de `assets/` et `cv-victor-travers.pdf`.

Le site est statique, sans chatbot IA et sans abonnement. Les photos et coordonnées figurant sur le site seront publiques une fois Pages activé.
